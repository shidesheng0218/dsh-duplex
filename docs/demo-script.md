## 90 秒视频（横屏优先，B 站竖屏可再剪）

1. **0–10s 痛点**：手上有活/在走路，DSH 在跑；键盘不在手边。
2. **10–28s 朗读 + 摘要**：点开一条长回复朗读；展示暂停/继续；"本轮用了 3 个工具：bash ×2、read"。
3. **28–48s 语音输入**：说需求 → 草稿 → 自动发送；中英混说。
4. **48–72s 语音审批（核心）**：
   - 普通操作：说"批准"即通过；
   - 高风险操作（bash）：说"批准"→ 二次确认"确认批准"→ 通过；
   - 说"取消"→ 不执行；
   - 听不清时脚本停在界面上，安全兜底。
5. **72–85s 提问/计划**：单选问题说"第二个"即可选中；计划评审说"批准"。
6. **85–90s 结尾**：安装一条命令 + 二维码 + "MIT / 非官方 / 不收集音频 / 无 LLM 代答"。
