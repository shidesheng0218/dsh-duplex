# dsh-duplex 演示脚本

> 目标：一条 30 秒 GIF（README 首屏）+ 一条 90 秒视频（B 站/YouTube）。
> 原则：先给"不可能"的一秒（离开键盘也能干活），再给数字。

---

## 30 秒 GIF（README 首屏）

| 秒 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–3 | DSH 会话界面，用户点回复旁的朗读按钮，按钮变成声波动画 | "让 DSH 开口"（EN: Let DSH speak） |
| 3–8 | 长回复被点读，代码块被跳过（画面里代码区域闪过"代码块"字幕） | "只念结论，不念代码" |
| 8–14 | 点输入框麦克风，说："跑一下测试，失败的两个修了" → 转写出现在草稿 | "说需求，不用打字" |
| 14–20 | 打开"自动发"，说完直接发送；助手开始干活 | 字幕：自动发送 |
| 20–27 | （v0.1 后）审批卡片弹出，语音播报"要删除 build 目录，批准吗？"→ 说"批准" | "语音审批" |
| 27–30 | 结束卡：logo + `dsh-duplex` + `Speak it, hear it.` | — |

录制建议：1080p、30fps、深色主题、终端字体 16px+；GIF 控制在 8MB 内（用 ffmpeg/gifski 压缩，必要时删到 20 秒）。

## 90 秒视频（B 站竖屏也可，横屏优先）

1. **0–10s 痛点**：手上有活/在走路，DSH 在跑；键盘不在手边。
2. **10–30s 朗读**：点开一条长回复朗读；展示暂停/继续；"代码块跳过"。
3. **30–55s 语音输入**：说需求 → 草稿 → 自动发送；展示中英混说。
4. **55–75s 语音审批（v0.1）**：破坏性操作双确认；会话里留下审批记录。
5. **75–90s 结尾**：安装一条命令 + 二维码 + "MIT / 非官方 / 不收集音频"。
